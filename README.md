# SIE Prep — FINRA SIE Exam Study Studio

A bilingual (English / Turkish), client-side study app for the FINRA Securities Industry Essentials exam. Built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

## Study features

- 102 original exam-style practice questions covering all four FINRA SIE content-outline sections and Easy / Medium / Hard difficulty.
- Question browser with section and difficulty filters, answer feedback, explanations, and rule references.
- Focused question sets and an 85-question, 105-minute mock exam with timer, flagged questions, strike-through, review sheet, calculator, and scratchpad.
- Section score breakdown, answer review, flashcards, and a high-yield reference sheet.
- English and Turkish interface and question translations.
- No login: study progress, language, flashcard state, and the preview membership state are kept in local browser storage.
- Weekly $7, monthly $19, and lifetime $100 plans are shown. Plan activation is a local preview only; a production payment provider and server-side entitlement checks are not connected.

## Question source note

The question bank consists of original practice questions written from public FINRA/SEC learning topics and the FINRA SIE content outline. It does not reproduce secure or copyrighted live FINRA exam questions, and it is not presented as a collection of past exam items. Rule references are study pointers, not legal or tax advice; verify current requirements with official sources.
